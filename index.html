  • Practica en una rama: git checkout -b practica.
  • Ten el proyecto corriendo en modo demo (bash run.sh) y los archivos clave abiertos.
  • Corre uv run pytest -q después de cada cambio.
  • Piensa en voz alta: qué archivo tocas y por qué.
  • Si te sobra tiempo, escribe un test.
